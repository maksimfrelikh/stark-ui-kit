The ⌘K command palette: a hint chip in the nav and an overlay with a combobox input over a listbox of commands.

Import `stark-ui-kit/command-palette.css`. Styling only — keyboard handling, filtering and focus management are the host's; the kit ships `trapTab` and `lockScroll` for the last two. The hint chip (`button.cmdk-hint` › `span.cmdk-key`) shares the theme toggle's chip language and hides under 680 px. The overlay (`div.cmdk-overlay[hidden]`) holds `div.cmdk[role=dialog][aria-modal]` with `.cmdk-top` (prompt, `input.cmdk-input[role=combobox]`, `kbd.cmdk-esc`) and `.cmdk-list[role=listbox]` of `p.cmdk-group` labels and `div.cmdk-item[role=option]` rows (label + mono hint). `.cmdk-item.active` is the keyboard cursor and what `aria-activedescendant` points at; it fills the row with `brand-fg` at 9 % and lifts the hint to `brand-muted`. Toggle with the `hidden` attribute — the entry animation runs on every open, closing is instant. Row corners are concentric with the card (`r-md` − list padding). The backdrop is `brand-scrim` + 2 px blur; no shadow.
