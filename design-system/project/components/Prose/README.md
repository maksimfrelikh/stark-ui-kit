Long-form typography for Markdown content: article bodies, FAQ answers — anywhere the markup carries no classes.

Import `stark-ui-kit/prose.css` and wrap the content in `.prose`; a title takes `.prose-title`, a lead paragraph `.prose-lead`. Layout is "narrow text, wide media": every child is capped at `--measure` (default 64ch of body text frozen to 36.672rem), while `header`, `pre` and `blockquote` span the full track. Links carry a quiet `brand-line-2` rule that the ink line flows over on hover; inline code is a chip mixed from `brand-fg`; code blocks get edge fades (`brand-scroll-shadow`) only when they actually overflow. The host may set `--measure` on `.prose` or any ancestor; it should also give overflowing `pre` blocks `tabindex="0"` and a name so keyboard users can scroll them.
